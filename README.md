## 一、三网优化优化的是回程，不是 ping 出来的那个数字

ping 测的是去程。你访问服务器，数据从国内运营商的国际出口出去，这段通常还顺；服务器把数据传回给你，走的是机房上游，这条回国通道才是国际拥塞的重灾区。看视频卡顿、SSH 输入延迟、下载中途掉速，多数发生在回程。所以"三网优化"实际优化的是回程路由，给电信、联通、移动各配一条相对干净的回国通道。

三条线路各管一摊：

- **电信 CN2 GIA**：电信的精品承载网，等级高于 CN2 GT，晚高峰稳定性好，价格也最贵。
- **联通 AS9929（CUII）**：联通精品网，业内常把它和 CN2 GIA 放在同一档讨论，性价比更好。
- **移动 CMI / CMIN2**：移动的国际精品回程，专门改善移动用户的回国体验。

普通美国 VPS 走 163 骨干，国内晚高峰拥堵时丢包、掉速是常态。优化线路有独立的优质出口，受影响小得多。

判断方法就两条：先看回程路由，再看去程；先看晚高峰八九点，再看空载 ping。空载 150ms 不代表晚上能用，商家给的测试 IP 用脚本跑一遍三网回程 tracert，比任何宣传词都可靠。

## 八、常见问题

**9929 和 CN2 GIA 哪个好？**
两者同属精品网级别。CN2 GIA 对电信用户体验最好，9929 对联通是原生优势线路，统一走 9929 的方案三网均衡性和性价比更好。你的用户以电信为主，CN2 GIA 更值；三网都有，9929 够用。

**晚高峰会不会掉速？**
优化线路受 163 骨干拥堵的影响比普通线路小得多，但没有任何线路能完全免疫高峰波动。判断依据是回程路由和实际晚高峰测试，不是商家页面上的"媲美专线"。

**1GB 内存能装 Windows 吗？**
LightLayer 提供 Windows 模板，最高到 Server 2025。但 1GB 内存跑 Windows Server 基本没有余量，要用 Windows 从 2GB 档起步更现实。

**流量超了怎么办？**
LightLayer 的 Standard 和 Global 档中有不限流量的配置，Premium 档按套餐走。DogYun 的做法是弹性云按量扣费、余额不足停机，经典云降速到约 1Mbps 但不断网。买之前确认自己的档位属于哪种处理方式，比事后补救有用。

**IP 被封了怎么办？**
商家层面能做的有限。Shandun 的经历说明同一商家不同段位风险差异很大，选一个邻居少的新段位比反复换商家更有效。LightLayer 的滥用条款按次罚款，被投诉和被墙是两件事，处理逻辑不同。

**续费会不会涨价？**
LightLayer 条款写明价格变动不适用于已有订单，续费不重新定价。这一条比首年折扣更值得看，很多低价套餐的坑就在第二年。
